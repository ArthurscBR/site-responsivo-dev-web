Sobre a Playverse

A Playverse é um projeto de site responsivo desenvolvido como parte da atividade avaliativa da disciplina de Desenvolvimento Web.

O objetivo do projeto é criar uma plataforma fictícia de jogos online, aplicando na prática conceitos de HTML e CSS estudados durante a disciplina.

🎮

Sobre o desenvolvimento

HTML

Utilizado para estruturar as páginas do site de forma organizada e semântica.

CSS

Responsável pelo design, cores, espaçamentos, efeitos visuais e organização dos elementos.

Responsividade

O layout foi pensado para se adaptar a diferentes tamanhos de tela, como computadores, tablets e celulares.

Objetivo da atividade

Este projeto foi desenvolvido para praticar conceitos importantes do desenvolvimento front-end, como Flexbox, CSS Grid, Media Queries, variáveis CSS, pseudo-classes, pseudo-elementos, animações e responsividade.

A página também utiliza uma animação criada com @keyframes, demonstrando o uso de animações CSS aplicadas a um elemento visual da interface.
